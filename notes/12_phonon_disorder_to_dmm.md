# 12（Stage 0b）：界面の乱れは AGF を DMM に漸近させるか —「可換化近似＝順序が平均化された極限」の第三の検算（2026-11-08）

問い（ご主人さま）：既知モデル（MS の R、余剰体積、AMM/DMM、自由電子 Bragg）は全部スカラーに畳んだ可換化近似で、残差は「順序・誰の目・整数性」に住む。なら DMM がよく合うのは界面の乱れが位相の履歴を消すときのはず。Stage 0 の延長で、界面ボンド（と中間層の質量）を対数正規に乱して（算術平均固定）、コヒーレント AGF が DMM に漸近するかを見る。

## 読み
1. **直接界面：乱れとともに透過スペクトルの形は単調に DMM へ近づく**（距離 0.56→0.28）。「履歴が消えると DMM の形になる」は成立。ただし **大きさは DMM を 20〜25% 超える**。乱れが k∥ 保存を破って新しい透過路を開く（Tian–Esfarjani–Chen 2012 の「界面粗さが Si/Ge の透過を上げる」と同じ向き）。→ **DMM は「形」の極限であって「大きさ」の極限ではない。大きさは依然として結合強度（κ）が決める。** Stage 0 の結論（効くのは κ）と整合。
2. **中間層あり：σ≈0.5 までは DMM に近づき、それ以上で離れて G が落ちる**（0.74）。6 層の中間層に強い質量乱れ → 局在（Anderson 型）。**DMM は「中間的な乱れ（拡散的）」の極限で、強い乱れの極限ではない。** 乱れの軸に三つの領域：コヒーレント（Fabry–Pérot、順序が生きる）→ 拡散（DMM、順序が平均化）→ 局在（順序が再び効く：経路が閉じる）。
3. ご主人さまの命題の精密化：**「可換化近似は順序が平均化された極限」は、平均化が*完全に*起きる中間領域でのみ成立し、両端（コヒーレント／局在）では順序が戻る。** これは電子の第3報（固定資源下で不均一性が中間 v で内部最大）と同じ U 字の構造。
4. ベンチマーク順の読みも補強される：Cu/TiC/diamond（結晶中間層、コヒーレント＋κ）→ Au/PMMA/Si（非晶・ポリマー、拡散側＝DMM の形に近いが大きさは κ）→ Al/Si・Al/GaN の G(T)（結晶、しかし非弾性＝別種の履歴忘却）。

## 保留・粗
- 乱れは対数正規で算術平均固定。実界面の乱れ（粗さ、混合層）とは分布が違う。
- Fabry–Pérot 縞のコントラスト指標は粗く、結論に使っていない。
- DMM はモード数計上版。実材料 DOS 版での「形の極限」の確認は Stage 1。
- 「G が DMM を超える」部分は、乱れで一部のボンドが幾何平均より強くなる効果（対数正規の尾）を含む。κ を全体に固定した乱れ（順列のみ）で切り分けるのが次。
