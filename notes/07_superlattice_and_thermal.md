# G：幾何 → モード結合 → 多重散乱 → 伝導 の階層を閉じる（2026-11-06 第7報）

コード `exp_G.py`、数値 `results_G.json`、`dataset_G.csv`（スペクトル特徴・残差込み）、`G4_GE.npy`（390 構造 × 41 エネルギーの G(E)）。

## G1：T 行列スペクトル — grid 残差は「集団共鳴」ではなかった — `figQ_G1_Tmatrix_spectrum.png`
M = I − G₀_dd U（E_F=−1.1, U=8t）の最小特異値 σ_min・log|det|・最小固有値・集団モードの参加比を 390 構造で計算し、M2″ の未知族残差と照合。

- σ_min の族中央値：grid 1.45、cluster 1.70、random 1.85、line 2.12。**どの族も σ_min > 1**。近特異（集団共鳴）な構造は E_F=−1.1 には存在しない。
- 残差との相関：σ_min r=+0.16（grid 内 +0.26）、log|det| −0.11、参加比 −0.03。弱い。
- スペクトル特徴を回帰に足すと **悪化**（0.885 → 0.879）。
→ grid の残差は、E_F での有限クラスターの集団共鳴（T 行列の極）では説明できない。σ_min が grid で最小なのは「周期配列は共鳴に近づく傾向」程度の弱い兆候。
→ 残差の正体は次の G2 が示す：**E_F の一点の極ではなく、エネルギーに広がった超格子ストップバンド**。

## G2：有限超格子（F2 の暗帯）＝無限周期系のストップバンド — `figR_G2G3_superlattice.png`
W=4 細線、行 1 に周期 a で欠陥 1 個のユニットセルを転送行列（2W×2W、a 列の積）で解き、|λ|=1 の Bloch 状態数 N_Bloch(E,a) を数えた。有限系（6 欠陥）の G/G0 マップと比較：

| U | corr(G, 自由電子 Bragg 距離) | corr(G, N_Bloch/N_open) | G: ストップバンド内 / 通過帯 |
|---|---|---|---|
| 0.5 | +0.08 | **+0.50** | 0.83 / 0.96 |
| 1.0 | +0.07 | **+0.62** | 0.72 / 0.90 |
| 2.0 | +0.04 | **+0.72** | 0.58 / 0.82 |
| 8.0 | +0.02 | **+0.76** | 0.42 / 0.69 |

- **有限 6 欠陥の暗帯は、無限超格子のストップバンドと一致する**（図の左列と中央列が目視でも重なる）。U が強いほど相関が上がる（ギャップが広がり、6 周期でも「無限系」に近づく）。
- 自由電子 Bragg 条件は **弱 U=0.5 でも相関ほぼゼロ**（G3 の答え：「単純 Bragg が有効な領域」は、この多チャネル細線では実質ない）。理由は 2 つ：(i) 弱 U のギャップは細い線で、距離指標が粗すぎる (ii) 多チャネルではチャネル間 Bragg（k_n + k_m = 2πm/a）と、欠陥が特定モードの腹／節に乗る効果（A_fwd_diag の物理）が同時に効き、単一チャネル Bragg 線では書けない。転送行列はこれを全部含む。
- 複素バンドの最小 Im K（右列）は減衰モードに支配されて指標としては粗い。ストップバンド判定（N_Bloch）の方が良い。

→ **「逆空間の幾何（S(q)）」の正しい後継は「有効バンド構造（転送行列の Bloch スペクトル）」**。これが第5報の保留事項の答え。

## G3：弱散乱での Bragg 回復 → 回復しない（上表）
U=0.5 でも Bragg 距離との相関 +0.08。代わりにストップバンド判定は U=0.5 から効く。「Bragg 条件」ではなく「超格子バンド」が最初から正しい言語。

## G4：有限温度平均 — grid 異常は熱で消えない — `figS_G4_thermal.png`
390 構造すべてで G(E) を E_F±0.5 の 41 点で計算（厳密 T 行列：清浄系の逆行列 41 回だけ）、Fermi 微分で平均して M2″ を再学習：

| kT [t] | 未知族 R² | grid RMSE | grid bias | std G: grid / random |
|---|---|---|---|---|
| 0 | 0.885 | 0.114 | −0.039 | 0.069 / 0.088 |
| 0.03 | 0.889 | 0.111 | −0.039 | 0.072 / 0.088 |
| 0.06 | 0.891 | 0.111 | −0.053 | 0.075 / 0.087 |
| 0.12 | 0.889 | 0.115 | **−0.063** | 0.078 / 0.087 |

- 熱平均で grid の過小予測バイアスは**消えないどころか微増**。grid の G(E) 分散もむしろ増える。
- つまり grid 効果は E_F の一点の鋭い干渉ではなく、**エネルギー幅 ≫ kT の広い構造**。これは G2 の結論（強散乱体のストップバンドは幅が U に比例して広い）と整合する。
- 実材料への含意：**周期配列由来の散乱増強は室温でも生き残る**（Cu の kT≈0.025 eV ≪ バンド幅）。

## 階層の現在地（閉じた形）

| 層 | 記述子 | 未知族 R² | 何を捉えるか |
|---|---|---|---|
| 幾何（実空間） | M2 | 0.80 | 欠陥数・射影被覆・局所相関 |
| 逆空間 | +S(q) | 0.81 | 周期性の波数整合（弱い） |
| モード結合 | +A_mn | **0.885** | 各横モードが欠陥をどれだけ感じるか（A_fwd_diag） |
| 多重散乱（集団共鳴） | +T 行列スペクトル | 0.879 | 効かない：E_F に極はない |
| 多重散乱（バンド） | 転送行列 / ストップバンド | （W=4 で corr 0.5〜0.76） | 周期配列の位相積み上げ＝超格子ギャップ |
| 完全 | NEGF | 0.96 | 上限 |

残り 0.885 → 0.96 の候補は、grid 残差の正体から見て、**局所周期性の有効バンド指標**（配置から局所的な周期ベクトルを抽出し、そのユニットセルの転送行列でストップバンド判定）。これは回帰特徴量として W=20 の一般配置に適用できる（次の一手）。
