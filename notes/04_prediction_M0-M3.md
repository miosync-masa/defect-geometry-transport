# D：G3 最小版 — 未知配置に対する予測実験 ΔL（2026-11-06 第4報）

コード `exp_D.py`、データ `dataset_D.csv`（580 構造）、数値 `results_D.json`。
訓練 360 構造（族 random / cluster / line / two-cluster × N_def∈{6,9,12,15,18}）、テスト (i) 同族・別 seed 100、(ii) **未使用族** arc / regular grid / wall+cluster 120。
目的変数 y = ln(1 − G/G0)。回帰は GBR（勾配ブースティング）と Ridge。

## 結果（GBR, R² / RMSE）

| 特徴セット | 同族テスト R² | 未知族テスト R² | 未知族 RMSE |
|---|---|---|---|
| M0 欠陥数のみ | 0.62 | **0.80** | 0.137 |
| M1 +幾何 | 0.86 | 0.46 | 0.227 |
| M2 +相関 | 0.87 | 0.66 | 0.179 |
| M3a +清浄系の局所電子応答（安価, G 情報なし） | 0.88 | 0.72 | 0.162 |
| M3b +構造込みバイアス応答（上限） | **0.98** | **0.96** | 0.061 |

特徴重要度（M3a）：**M1_yproj（横方向射影被覆）0.68**、M3a_ldos_sum 0.18、残りは 0.02 以下。

## 読み
1. **同族では ΔL は階段状に効く**：M0→M1 で R² 0.62→0.86（幾何の追加価値が最大）、相関・局所応答で微増、構造込み応答で 0.98。「壁⊥の物理」＝横方向射影被覆が単独で支配的。
2. **未知族では幾何記述子が M0 に負けた**（0.80 → 0.46）。これは失敗じゃなく G3 の設計が正しく機能した証拠。原因は parity 図で明瞭：**規則格子族 (grid) が系統的に過小予測**される。M2 は grid を一律 1−G≈0.28 と予測するが、真値は 0.2〜0.5 に広がる。周期配置は Bragg 的な干渉で散乱が増強されるが、局所相関記述子（最近接距離・クラスター・g(r)）は周期性を見ていない。H2（離散・干渉）が記述子の穴として現れた。
3. **M3a（清浄系 LDOS 和・欠陥間伝播子）は未知族への転移で M2 を救う**（0.66→0.72）。物理量に根ざした記述子の方が外挿に強い。M3b は上限として 0.96。
4. M0 が未知族で「効く」のは、arc/grid では欠陥数が支配的で、幾何の外挿誤差が無いだけ。安全だが情報が無い。

## 次の一手（第5報候補）
- **構造因子特徴**：S(q) = |Σ_j e^{iq·r_j}|² を各開チャネルの 2k_x,n で評価し M2' に追加 → grid の過小予測が消えるか（Bragg 仮説の直接検証）。これは H3 の「2k_F 対応」保留事項とも同じ軸。
- Ridge は M1 以降で発散（aniso=λmax/λmin が線分で ∞）→ log 変換・クリップ。
- 配置座標を保存して再計算可能に（今回は未保存、再実行 8 分）。
- 未知族をもう 2 つ（ランダム+周期混在、2 列壁）追加。
