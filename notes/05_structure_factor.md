# E：逆空間の幾何 — 構造因子 S(q) を記述子に（2026-11-06 第5報）

問い：「電子は欠陥の位置だけでなく、欠陥配置が持つ空間周波数を見ているのではないか？」
コード `exp_E.py`（族生成・幾何特徴は `exp_D_fams.py` に分離、aniso は log 化）、座標 `coords_E.json`（**全構造保存**）、数値 `results_E.json`, `results_E_D3.json`。
E_F ∈ {−1.5, −1.1, −0.7}（開チャネル 12/13/15）、各 390 構造（訓練 240、同族 60、未知族 90）。

## S(q) 記述子の定義
S(q) = |Σ_j e^{iq·r_j}|² / N_def²（ランダムなら ≈ 1/N_def）。チャネル n の縦波数 k_n、横波数 k_y,n = nπ/(W+1) から
- S_back：チャネル内後方散乱 q=(2k_n, 0) の平均
- S_inter：チャネル間反射 q=(k_n+k_m, k_y,n ∓ k_y,m) の平均
- S_fwd：チャネル間前方散乱 q=(k_n−k_m, k_y,n ∓ k_y,m) の平均
- 対照 Sgrid：電子と無関係な固定 q グリッド上の S の最大・平均

## D1：M2 + S(q) で grid 残差は減るか — `figM_E_Sq_deltaL.png`

| データ E_F | M2 novel R² | +Sgrid（電子非依存） | +S(q)@正しい E_F | grid RMSE: M2 → +S(q) |
|---|---|---|---|---|
| −1.5 | 0.672 | 0.658 | 0.728 | 0.253 → 0.225 |
| −1.1 | 0.789 | 0.735 | 0.805 | 0.182 → 0.180 |
| −0.7 | 0.796 | 0.801 | 0.842 | 0.209 → 0.175 |

- **電子波数で評価した S(q) は未知族 R² を +0.02〜+0.06 改善、grid RMSE を最大 17% 削減。電子と無関係な Sgrid は効かないか悪化。** → 改善は「逆空間の幾何」一般ではなく、**散乱波数に整合した成分**から来ている（波数整合仮説を部分支持）。
- ただし grid のバイアスは −0.08〜−0.16 で**負のまま**。S(q) で埋まったのは残差の一部。
- 重要度：S 系では **S_fwd（チャネル間前方散乱）が最上位**（0.05〜0.08）、S_back（2k_F 後方散乱）は末尾。多チャネル細線では「反射」より「モード混合」の方が記述子として効いている。これは予想と違った点で、面白い。

## D2：E_F を変えて残差が電子波数に追従するか
- E_F=−0.7 のデータでは、**正しい E_F の S(q)（0.842）が、他の E_F の S(q)（0.808, 0.808）より明確に良い**。追従あり。
- E_F=−1.1、−1.5 では差が 0.01〜0.02 で判別不能（−1.5 ではむしろ −1.1 の k で評価した方がわずかに良い）。
- 理由の候補：隣接する E_F の k_n 集合が大きく重なる（12〜15 チャネルの k が広く分布）ので、S(q) の評価点がほぼ同じ。E_F 差をもっと大きく取るか、単一チャネル（細い W）で切り分けるべき。**追従は「ある」が、この設計では弱い証拠**。

## D3：配置固定・周期だけ変える — `figN_E_D3_period.png`
縦周期（1 行に 8 欠陥、周期 a=1..6）：

- 同じ 8 欠陥でも周期で G が 0.67〜0.97 と変わる（a=1 は shadowing で透明、a=3 で最も散乱）。**非単調で、周期が効く**ことは確定。
- しかし最小位置 a=3 は E_F によらずほぼ同じ → 単純な Bragg 条件 a*=π/k_n の追従は見えない。多チャネルで k_n が 0.5〜2.0 に散らばり、Bragg 条件がチャネルごとに違う周期に来て平均化される、が自然な解釈。
- 横周期スキャンは N_def が周期と連動して変わる設計ミス（b=1 は壁⊥ 20 個、b=7 は 3 個）で、周期効果と欠陥数効果が混同。**やり直し要**（N 固定で周期だけ変える）。

## 読みと次
1. 逆空間記述子は効く。しかも効くのは電子の散乱波数に整合した成分で、特に**チャネル間前方散乱 S_fwd**。「電子は空間周波数を見ている」は部分的に Yes。
2. E_F 追従は E_F=−0.7 でだけ明瞭。切り分け実験としては W を細く（2〜3 チャネル）した系で D2/D3 を再実行するのが筋 → 単一 Bragg 条件が出るはず。
3. grid の残差はまだ残る。候補は **超格子ミニギャップ／準束縛状態**（周期配列は 1 次元超格子として振る舞い、E_F がミニギャップに入ると透過が落ちる）。これは S(q) では書けず、周期配列の分散関係（有効 1D バンド）を記述子にする必要がある → 「逆空間の幾何」の次は「有効バンド構造」。
4. M2 の novel R² が第4報 0.66 → 今回 0.79（E=−1.1）と動いた。サンプルと族生成 seed の差。**族別・seed 別の分散を報告する習慣**を入れる。
