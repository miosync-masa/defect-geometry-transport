# H：局所周期性 → 有効ユニットセル → Bloch 伝播条件（2026-11-06 第8報）

コード `exp_H.py`、`dataset_H.csv`、`results_H.json`。
訂正（第7報 G4 の範囲）：G4 は**静的欠陥ポテンシャルに対する Fermi 窓のエネルギー平均**のみ。フォノン散乱・位相緩和・粒界構造の温度変化は含まない。言えるのは「熱的エネルギー平均だけでは grid 効果は消えない」まで。実 Cu 室温での残存は次の物理層で確認。

## 設計
- H1（対照）：重みなし並進自己相関 C(Δ) の最大で周期候補 a₁
- H3：モード重み付き自己相関 C_n(Δ)=Σ φ_n(y_j)²φ_n(y_j')²δ(x_j−x_j'−Δ) を開チャネルで 1/v_n 加重 → 「電子が感じる周期」a₃、ピーク鋭さ、モード間一致率
- H4：a₃ で有効ユニットセル。セル当たり行占有率 occ_r から U_eff,r = U·occ_r（仮想結晶平均）、または二値化（occ≥0.5）。2W×2W 転送行列（W=20 → 40×40）で Bloch 伝播割合 N_Bloch/N_open と最小減衰率 Im K。E_F±0.1 平均版も。

## 結果

|---|---|---|---|

- 周期の再発見：grid 族で H1・H3 とも真の周期 dx を **100%** 回復。H3_peak の族中央値は grid 5.6 > cluster 4.6 > wall+cluster 4.5 > two 2.9 > line 2.6 > arc 2.1 > random 1.9 で、周期秩序の順位付けとしては正しく働く。

- 目標値 0.92〜0.95 には届かなかった。これは正直に「二層目の記述子化はまだ」。

## なぜ効かなかったか（これが収穫）
W=4 細線で、周期配列の長さ N_d を変えて「有限系の G が無限超格子のストップバンドにどれだけ従うか」を測った（U=8）：

| 周期数 N_d | corr(G, Bloch 割合) | G: ストップ帯 / 通過帯 |
|---|---|---|
| 2 | 0.37 | 0.64 / 0.74 |
| 3 | 0.54 | 0.55 / 0.69 |
| 4 | 0.66 | 0.49 / 0.69 |
| 6 | 0.76 | 0.41 / 0.69 |
| 10 | **0.83** | 0.37 / 0.70 |

→ **集団伝播（ストップバンド）が伝導を支配するには周期が ≳4〜6 必要**。W=20 の grid 族は x 方向に 3〜4 周期しかなく、しかも幅方向は部分被覆。この領域では「無限超格子の Bloch 条件」はまだ立ち上がりきっておらず、G は少数セルの干渉＋モード重なり（A_mn が既に捕捉）で決まる。さらに仮想結晶平均 U·occ は強散乱体の周期配列を別の物理（弱い平均場）に置き換えてしまう。
→ H4 が効かなかったのは記述子の設計ミスというより、**このトイの grid 族が「集団伝播レジーム」に入っていない**から。第7報 G2 で W=4・6 周期では効いたのと整合する。

## 論文の核への含意
「界面欠陥の電子輸送を、モード選択と集団伝播という二つの機構で説明する」
- モード選択：A_mn で記述子化・予測実験で検証済み（0.80→0.885）。
- 集団伝播：機構としては G2/F3/G4 で同定済み（有限＝無限ストップバンド、周期配列ほど高次散乱、熱に頑健）。**記述子として効く条件＝周期数 ≳4〜6** を今回定量化。トイの未知族ではその条件を満たす配置が少ないので予測性能には現れない。
- つまり二層は「互いに補完する」というより「**レジームが違う**」：少数周期ではモード選択が支配し、多周期で集団伝播が立ち上がる。これは「どちらの記述子をいつ使うか」の判定基準（周期数・H3_peak）として書ける。

## A（実 Cu CSL）への接続が逆に強くなる
実 CSL 粒界の面内周期は構造単位の繰り返しで**事実上無限**。トイで必要だった「局所周期の抽出」も「周期数の不足」も、実結晶では最初から解消されている。
ご主人さまの区別どおり、トイの W=4 超格子は**輸送方向**の周期（ストップバンド）、CSL の面内周期は**面内運動量の結合条件**（Umklapp）を決める。後者は「面内 Bloch モードを基底にした界面散乱問題」として定式化する：
  面内 Bloch 基底 {ψ_{k∥+G∥}} → 界面ポテンシャル V_GB の行列要素 M_mn → 透過固有値 {T_n} → N_eff, D_eff, G
これはトイの A_mn（横モード基底）をそのまま面内 Bloch 基底に置換した形で、新しい道具は要らない。

## 次（残った中心課題への別ルート）
1. **多周期 grid 族を未知族に追加**（x 方向 6〜8 周期、全幅）して、H4 がそのレジームで効くかを予測実験で確認 → 「レジーム依存の補完」を数値で示す。
2. 有効ユニットセルを平均場でなく**実パターン**（a₃ 列の窓内の実際の欠陥配置）で構成。
3. 少数周期レジームの残差は、A_mn の 2 次合成（pair 相当）か少数セル干渉項で埋める。
