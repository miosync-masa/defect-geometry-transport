## 1. まず動かした：2D タイトバインディング + Landauer–NEGF

- 格子: 正方格子 W=20 × L=40、半無限リード（Sancho–Rubio）、E_F = −1.1t → 開チャネル N = 13、清浄系 T0 = 13.00（検算OK）
- 欠陥: オンサイト U = 8t（強散乱体＝空孔の代理）
- コード: `negf_toy.py`（コア）, `run_experiments.py`（実験A–D）, 結果 `results.json`

### Exp A — H1/H4「同じ欠陥数 (12個)、配置だけ変える」 → `figA_geometry.png`

| 配置 | T/T0 |
|---|---|
| 壁 ⊥ 輸送（粒界面相当） | **0.468** |
| 2本の半壁（オフセット） | 0.469 |
| 対角線 | 0.507 |
| ランダム (n=150) | 0.653 ± 0.025（min 0.60, max 0.72） |
| 疎な壁 ⊥（1行おき） | 0.646 |
| 3×4 クラスター | 0.831 |
| 壁 ∥ 輸送 | **0.961** |

**同じ欠陥数で伝導が 2倍違う。** 研究の最初の問い
「同じCu＋同じ欠陥数＋異なる欠陥配置 → 異なる電気的応答？」の答えは、トイモデルの範囲で **Yes**。
しかもランダム配置の分布幅（σ≈0.025）より、構造化配置の差（0.47〜0.96）の方が桁で大きい → 「平均密度では説明できない幾何記述子がある」(期待成果1) の芽。

右パネル（透過固有値 T_n）が面白い：
- 壁⊥：n≤5 は完全透過、n≥7 はほぼ遮断 → **チャネルが「生き残る/死ぬ」の二値的** ＝ 接続性 F 型
- クラスター：n≤10 まで完全透過、最後だけ落ちる → 局所的・少数チャネル型
- ランダム/疎な壁：なだらかに減衰 → 局所透過 D 型
→ 同じ G でも **チャネル分解すると「D で落ちたのか F で落ちたのか」が区別できる**。これが観測窓の第一候補。

### Exp B — H3「2欠陥の非加法性」 → `figB_pair_nonadditivity.png`

η(d) = ΔT_AB − (ΔT_A + ΔT_B)、単独欠陥の損失 ΔT = 0.480。
- 輸送方向に隣接 (Δx=1): η = **−0.45**（2個で1個分しか効かない＝影に入る、shadowing）
- Δx=3: +0.02、Δx=4: −0.06 … と **符号が振動して減衰**（Friedel/2k_F 型の干渉）
- 横方向 (Δy): ±0.05 で振動、減衰が遅い
→ 「欠陥間距離・相対方向で非加法性」(H3の予測) は出る。しかも **方向で振動の周期と減衰が違う**（H4 と H3 が結合）。

### Exp C — 粒界「余剰体積」を制御座標にする → `figC_gb_freevolume.png`

粒界面を 1列のボンド弱化 t' = t·e^{−βv}（β=3）で模倣。v = 粒界余剰体積の代理。
- 秩序粒界: G/G0 は v に対して単調減衰（**減衰型 regime**）
- 乱れ粒界（ボンドごとに弱化率がばらつく）: v>0.3 で秩序粒界より **高い** G が残る → 不均一さが「生き残りチャネル」を作る（パーコレーション的接続性 F の効果）
- 弱化＋粒界ポテンシャル: さらに減衰が速い
- トイ N×D×F 分解（N=開チャネル、F=T_n>0.1 の割合、D=その平均）: v<0.3 では F=1 で D だけが落ちる（＝局所ホッピング支配）、v>0.3 で F が崩れ始める（＝接続性支配）。**SSOC の PCC→SCC 境界 (v_c) と同じ形のクロスオーバーが出る。**

### Exp D — 観測窓：局所電流分布 → `figD_current_maps.png`
壁⊥では電流が壁の両端 2 本に集中（電流集中＝局所電場・電位降下の集中の前触れ）。壁∥ではほぼ乱れなし。ランダムは面全体にムラ。
→ 「最終コンダクタンスではなく、その手前の空間応答を観測する」が絵として成立。

## 2. ご主人さまの論文から持ち込める構造（「関係ないけど役立ちそう」の正体）

### 2.1 乗法分解 σ = N × D × F → G_GB = N_ch × D_local × F_conn
Universal Decomposition 論文の核。Cu粒界では
- N: 開チャネル数（Fermi面幾何・断面積；キネマティック）
- D: チャネル当たり局所透過（原子スケールのバリア＝ホッピング弱化、配位数低下）
- F: チャネル接続性（どれだけのチャネルが粒界を「貫通」するか；パーコレーション）
Exp C の分解はまさにこれで、**「どの項が支配するか」が v で切り替わる**。論文の主張「普遍なのはパラメータでなく分解構造」をそのまま継承できる。

### 2.2 v_f = 1 − ρ/ρ_0 → 粒界余剰体積 (GB excess volume)
粒界物理には古典的に **余剰体積 ΔV/A** がある（粒界エネルギーと強相関、Σ3 コヒーレント双晶はほぼ 0、一般大角粒界は大）。
SSOC の v_f が「製造変数（密度）と輸送をつなぐ単一座標」だったのと同型で、**粒界余剰体積が「アニーリング履歴 → 構造 → 輸送」をつなぐ単一座標の第一候補**。H5（製造履歴）とそのまま接続する。
ρ_0 の定義が系ごとに違ってよい、という論文の整理（構造的普遍性 vs パラメータ的普遍性）も、Σ値ごとに基準が違う粒界にそのまま使える。

### 2.3 PCC/SCC 分離 → 欠陥の加法性/非加法性
- PCC: 欠陥の効果が足し算で効く領域（Matthiessen 則が成り立つ）
- SCC: 欠陥同士が協同して閾値的に効く領域（H3 の非加法性、Exp B の shadowing、Exp C の F 崩壊）
Hill n=3 の「CN≥3 で Li サイトが生きる」は、Cu なら **「配位数 CN ≥ k で伝導チャネルが生きる」** という SCC ゲートに翻訳できる。fcc CN=12 からの欠損で閾値があるか、は面白い検証対象。

### 2.4 ピーク型 / 減衰型のレジーム分類
Cu粒界で単純に v を増やすと減衰型。でも **ピーク型が出る条件** を探すのが枝になる：
- 粒界ポテンシャルが共鳴準位を作る（界面状態が Fermi 面に来る）と透過が増える可能性
- 不純物偏析（H2 の離散性）が局所的にバリアを「埋める」場合
→ 「Cu粒界にピーク型は存在するか？」は研究計画に無い新しい問い。

### 2.5 Θ·σ = Λ_th 型の因数分解恒等式 → Mayadas–Shatzkes の R と λ/d
MS モデルは ρ_GB/ρ_0 = f(α), α = (λ/d)·R/(1−R)。これは **「材料固有の反射係数 R」×「幾何 λ/d」** の因数分解で、Θ·σ=Λ_th と同じ設計思想。
ご主人さまの研究は「R を構造から出す」こと。つまり
  **構造 S → R(S)（本研究） → MS 幾何因子 → 配線抵抗（デバイス）**
という 3 層チェーン（AEnM 論文の σ→Θ→format と同型）が組める。設計箱（Design Box）形式まで持っていける。

### 2.6 熱–イオン分離 (A2) の「逆」
AEnM 論文では熱伝導と イオン伝導を分離できた。Cu では **電子が電荷も熱も運ぶ（Wiedemann–Franz）** ので分離しない。逆手に取ると、**粒界での Lorenz 数のずれ L/L_0 が構造記述子** になる（弾性 vs 非弾性散乱の比を反映）。研究計画の保留事項「電子–フォノン」への入口。

### 2.7 二段階独立フィット（Stage1: D_hop → Stage2: f_eff）
過学習防御の方法論。Cu でも **Stage1: 単一欠陥・秩序粒界で D を決めて固定 → Stage2: 配置・相関から F を抽出** にすれば、8 パラメータ同時フィットを避けられる。査読対策として先に設計しておく価値あり。

## 3. 新しく生えた枝（研究計画 v0 に無かったもの）

1. **チャネル分解を観測窓にする**：局所電位分布より先に、透過固有値スペクトル {T_n} を「応答記述子」にする。D 型減衰（なだらか）と F 型減衰（階段）が同じ G で区別できる（Exp A 右）。
2. **ピーク型粒界の探索**：界面共鳴・偏析で G が増える条件を v–ε_GB 平面で地図化。
3. **粒界余剰体積を製造履歴から**：MD/KMC でアニール温度・時間 → ΔV/A の分布 → Exp C 曲線に乗せる。SSOC の「焼結→密度→σ」と完全同型の因果鎖。
4. **shadowing 長**：Exp B の η(Δx) が負から振動に転じる距離 ≈ 2〜3 格子。これを「欠陥相関長 ξ_c」として定義し、欠陥密度 n と ξ_c の積で PCC/SCC 境界を予測（SSOC の v_c の役割）。
5. **不均一性が伝導を守る**：Exp C の乱れ粒界が高 v で勝つ。「均一に悪い粒界」より「ムラのある粒界」の方が良い、は設計指針になりうる（粗、要検証）。
6. **Lorenz 数記述子**：電気だけでなく熱の NEGF も同じ G^r から出るので追加コストが小さい。

## 4. 粗いところ（隠さず置いておく）

- 2D 正方格子・単一バンド。Cu の s–d 混成、fcc、3D は未着手。Exp C の粒界は「1列のボンド弱化」で、傾角粒界の実構造ではない。
- Exp C の「乱れ粒界」は弱化**指数**の平均を揃えただけで、ホッピングの平均値は揃っていない（Jensen）。差の一部は Jensen 効果。
- N×D×F の閾値 (T_n>0.1) は恣意的。参加比などで定義し直す余地。
- 局所電位（Poisson 自己無撞着）はまだ無い。今あるのは局所電流と LDOS。静的遮蔽応答 R(E_ext) は次段。
- 非弾性散乱・有限温度・スピンなし（計画どおり保留）。
