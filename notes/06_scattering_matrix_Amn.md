# F：構造因子から散乱行列へ（2026-11-06 第6報）

コード `exp_F.py`、データ `dataset_F.csv`（390 構造、E_F=−1.1、第5報の座標を再利用＝NEGF 再計算なし）、数値 `results_F.json`, `results_F3_Uscan.json`。

## 技術的な鍵：欠陥サイト上の厳密 T 行列
オンサイト欠陥なら T_dd = U(1 − G₀_dd U)⁻¹ を欠陥サイト（≤18 個）上で厳密に構成でき、G = G₀ + G₀ T G₀ を Fisher–Lee に入れると **NEGF と 10⁻¹⁵ で一致**。
→ 清浄系 G₀ を 1 回計算すれば、任意の配置・任意の U で G が瞬時に出る。しかも級数を途中で切れば「独立散乱体（ISA）→2体（pair）→完全」の多重散乱階層が同じ枠で出る。ISA は欠陥効果の加法（PCC）、それ以上は非加法（SCC）に対応。

## F1：チャネル結合幾何 A_mn（M2″）— `figO_F_hierarchy.png`
A_mn = Σ_j φ_m(y_j)φ_n(y_j) e^{i(k_n∓k_m)x_j}/√(v_n v_m)。φ_n は横モード波動関数。特徴量：A_back_diag（チャネル内後方）、A_back_off（チャネル間反射）、A_fwd_off（チャネル間前方混合）、A_fwd_diag（チャネル内前方＝各モードが欠陥を「感じる」重み）、A_born_R（Born 1 次総反射）、A_evan（減衰モードへの結合）。

| 記述子階層 | 未知族 R²（5 seed） | 同族 R² | grid RMSE | grid bias |
|---|---|---|---|---|
| M2 実空間 | 0.799 ± 0.008 | 0.866 | 0.177 | −0.136 |
| M2′ +S(q) | 0.806 ± 0.015 | 0.877 | 0.179 | −0.135 |
| **M2″ +A_mn** | **0.885 ± 0.002** | 0.873 | **0.113** | **−0.039** |

- **A_mn が今までで最大の一段**：未知族 R² +0.08、grid RMSE 37% 減、grid バイアスはほぼ消えた（−0.136 → −0.039）。seed 分散は 0.002 で、F5（分割依存性）の懸念は小さい。
- 重要度：M1_yproj 0.275、**A_fwd_diag 0.274**、A_born_R 0.235、その他は 0.05 以下。S(q) 系は 0.03 以下に落ちた（A_mn に吸収された）。

### S_fwd の 3 解釈への答え
第5報で効いた S_fwd の正体は **A_fwd_diag = |Σ_j φ_n(y_j)²|²/v_n**。これは「散乱」というより、**各横モードが欠陥配置をどれだけ強く感じるか（モード分解された射影被覆）**。grid が M2 で過小予測されたのは、規則格子の y 周期がある横モードの腹にちょうど乗る／節に落ちるので、同じ yproj でもモードごとの重みが全然違うから。
→ 解釈 **B（代理記述子）が主**：S_fwd は横モード重なりの代理だった。A（前方混合そのもの）は A_fwd_off の重要度 0.05 以下で副次的。C（高次多重散乱）は下記 F3 で別途支持。

## F3：多重散乱階層（直接比較、回帰なし）— `results_F3_Uscan.json`
U を 0.5〜8t で振り、切断級数の G 予測と厳密値の RMSE（ln(1−G)）：

| U | pair 近似 RMSE: grid / random | 2 次 Born: grid / random | 備考 |
|---|---|---|---|
| 0.5 | 0.15 / 0.11 | 0.50 / 0.39 | 弱散乱：pair でほぼ足りる |
| 1.0 | 0.35 / 0.21 | 1.8 / 2.7 | grid の方が高次を要求 |
| 2.0 | 2.0 / 0.65 | 破綻 | **grid の pair 誤差が random の 3 倍** |
| 8.0 | 3.5 / 3.8 | 破綻 | 強散乱：全次数の再和が必須 |

- Born 1 次は構造上 G>1 を出す（光学定理を満たさないので伝導の予測子にならない）。最低次で意味があるのは 2 次／pair。
- **U=1〜2 で、周期配列（grid）はランダムより系統的に高次の多重散乱を要求する。** これが解釈 C の定量的支持：周期配列では欠陥間の多重反射が位相を揃えて積み上がる。
- U=8t（今までの設定）は完全に強散乱領域で、切断近似はどれも無意味。A_mn が特徴量として効いたのは Born が正しいからではなく、GBR が Born 振幅から非線形写像を学んだから。**実 Cu の空孔・不純物は U がバンド幅程度（中間領域）**なので、U=1〜2 の結果が一番参考になる。

## F2：少数チャネル（W=4、≤3 チャネル）の周期×E_F マップ — `figP_F2_period_energy_map.png`
- 周期 a と E_F の平面で G/G0 は **はっきりした帯構造**を持ち、暗い帯（透過 ≈0）が E_F とともに移動する → 周期効果はエネルギーに追従する（F2 の予測どおり）。
- しかし自由電子の Bragg 条件 a = mπ/k_n(E) との相関は **0.015**（Bragg 線近傍 G=0.49、遠方 0.52）。追従はするが、**追従先が Bragg 線ではない**。
- 解釈：U=8t の 6 欠陥は「弱い周期ポテンシャル」ではなく「強散乱体の有限超格子」。暗い帯は Kronig–Penney 型の**超格子ストップバンド**で、位置は強散乱体鎖自身の分散で決まる。第5報で予告した「逆空間の幾何の次は有効バンド構造」がここで必要になった。
- 弱 U で同じマップを取れば Bragg 線に乗るはず（次の確認）。

## 記述子階層の現在地
M2（実空間）0.80 → M2′（S(q)）0.81 → **M2″（A_mn）0.885** → NEGF 上限（M3b）0.96。
残り 0.08 のうち、F3 から見て大半は**多重散乱（配置依存の位相積み上げ）**。安価に埋める候補は「pair を超えた再和」ではなく、**強散乱体鎖の有効分散（超格子バンド）**か、A_mn の 2 次合成 Σ_l A_ml g_l A_ln（これは pair と同等）。

## Cu への写像（添付の A1〜A5 に対応）
- A_fwd_diag が効いた＝「どの横モードに欠陥が乗るか」。実 Cu では **粒界面内の原子位置と Fermi 面上のモードの面内波動関数の重なり M_mn = ⟨ψ_m|V_GB|ψ_n⟩** に直結（添付 §2 の精密化どおり）。CSL 周期 → {G_∥} → M_mn → {T_n} → G。
- F3 の「周期配列ほど高次散乱が要る」は、A4（周期秩序と無秩序の競合）の電子側の根拠：秩序粒界は特定モード対に散乱を集中させ位相を積み上げる。「結晶学的に整った粒界 ≠ 電子輸送に透明な粒界」の機構候補。

## 保留
- 弱 U（1〜2t）での F2 マップと Bragg 線照合。
- A_evan（減衰モード結合）は重要度 0.007 だが、grid の残差と相関するかは未検証（共鳴・準束縛の種）。
- 横モード φ_n は清浄細線のもの。実粒界では面内ブロッホ関数に置換。
- F4（有限温度エネルギー平均）は未実施。厳密 T 行列で E 掃引が安価になったので次回。
